# Checklist de publicación

- [ ] Revisar ortografía, empresas, cargos y fechas frente al CV original.
- [ ] Verificar que el email y LinkedIn pueden ser públicos.
- [ ] Confirmar que se permite publicar la fotografía en un repositorio público.
- [ ] Ejecutar `npm install` y `npm run build` con Node.js 22.
- [ ] Ejecutar `npm run preview` y navegar por todos los capítulos.
- [ ] Revisar el avatar 3D en cada sección y la foto de fallback sin WebGL.
- [ ] Revisar `public/cv.html` e imprimirlo a PDF.
- [ ] Comprobar tablet y móvil, teclado, navegación, enlaces y `prefers-reduced-motion`.
- [ ] Crear repositorio y subir el contenido del ZIP, incluida `.github`.
- [ ] Seleccionar Settings → Pages → GitHub Actions.
- [ ] Validar el deployment en `https://USUARIO.github.io/REPO/`.
- [ ] Si se usa dominio propio, ajustar `GITHUB_PAGES_BASE` y metadatos sociales.
